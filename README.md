# 灰岩的案件手帳｜商店街的生意經

[開始公開試玩](https://sora0811.github.io/Grey_index_test/street.html)

Prototype v0.2 場景整合版。調查三間店、五名人物與無主手推車，使用關鍵字交叉詢問，再到手帳整理自己的理解。可帶著部分理解結案，也可重新調查；不評分、不顯示完成比例。

## 操作

手機直握可左右滑動街道，或使用左右按鈕。點選調查對象，再展開底部訊息。選單可切換物件標記；貨物內容須調查後才會出現在訊息與手帳中，場景不顯示材料名稱。

進度自動儲存在目前瀏覽器，無跨裝置同步。選單可重置本案。保留既有存檔鍵 `greyrock.case02.v01`，更新不會清除進度。

## 公開範圍

公開入口只提供商店街。首頁 `index.html` 會轉往 `street.html`；第一案測試品已撤下，原始版本保留於 Git 歷史，沒有公開遊玩入口。

## 回饋

請附裝置／瀏覽器、卡住的步驟、預期與實際反應；可至 Repository Issues 留言。首次試玩請勿先閱讀程式與測試紀錄，以免看到調查內容。

## 素材與部署

使用專案使用者提供的商店街場景原圖，未使用網路搜尋圖片。來源與使用範圍見 [ASSETS.md](ASSETS.md)。原圖約 3.27 MB。

純 HTML／CSS／JavaScript，無需建置。GitHub Pages 從 main 根目錄發布，全部資源使用相對路徑，無外部字型、追蹤或資料上傳。離線遊玩請保留 `street.html`、`street.js`、`street-scene.css` 及 `assets/`。

驗證紀錄與限制見 [TESTING.md](TESTING.md)。未測實體手機、Safari 與慢速網路；目前僅保存一份結案理解。
